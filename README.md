
# TODOListSolution

A task management REST API built with C# and ASP.NET Core.

This project explores backend API development with .NET, focusing on organizing task-related functionality into a structured solution and exposing it through HTTP endpoints.

## 🎯 Objectives

- Practice building RESTful APIs with ASP.NET Core.
- Develop a structured and maintainable backend application.
- Work with HTTP methods, routing, and request handling.
- Improve understanding of C# and modern .NET development.
- Build a foundation for adding more advanced task management features.

## 🛠️ Tech Stack

- **C#** — Programming language
- **.NET / ASP.NET Core** — Backend framework
- **REST API** — HTTP-based API design

Additional technologies depend on the current implementation.

## 🚀 Getting Started

### Prerequisites

- .NET SDK compatible with the project
- Git

### 1. Clone the repository

```bash
git clone https://github.com/SoulT2Sell/TODOListSolution.git
cd TODOListSolution
```

### 2. Restore dependencies

```bash
dotnet restore TODOListSolution.sln
```

### 3. Build the solution

```bash
dotnet build TODOListSolution.sln
```

### 4. Run the API

Navigate to the API project directory:

```bash
cd TODOListSolutionApi
dotnet run
```

Use the URL displayed in the terminal to access the running API.
